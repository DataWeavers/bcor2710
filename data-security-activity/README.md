# Data Security Management at Canvas

An in-class activity for BCOR 2710 (Business Information Technology) at Loyola Marymount University.

Students act as advisors to Canvas after its 2026 data breach. They read a blueprint of a security plan and choose the better option in each blank, across the three types of security safeguards: human, data, and technical. Three of the questions deal with risks that AI has created.

## Using it

Open `index.html` in any browser. No install, login, or server is needed. If GitHub Pages is turned on for this repository, students can open it from the Pages link for this folder.

1. Students choose one option in each of the 25 blanks (23 numbered questions).
2. **Check answers** grades everything at once and shows a short explanation under every question.
3. **Save results image (PNG)** downloads an image with the student's name, the date and time, the score, a breakdown by safeguard, and a numbered answer map. Students submit that image.

Answers are saved only in the student's own browser, so a refresh doesn't lose their work. Nothing is sent anywhere.

## Note for instructors

The page grades itself in the browser, so the answers are in the page's source code. Treat it as practice or a participation activity, not a secured quiz.
